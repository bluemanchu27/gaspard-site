# Agent portal files

Form files for the members-only agent portal (/agent-portal/) go in this folder.
List each one in content/portal.json. The site only publishes these files
behind the agent logins; if the logins aren't set in Netlify, the portal and
these files are left off the site entirely.

Only blank forms and company-wide documents belong here. Signed agreements or
anything with one agent's personal terms (splits, licenses, W-9s) do not.
